# Exploring Secrets Management

A key feature of OPA is the vault and the ability to store/manage/access
secrets (such as credentials). This section of the guide will walk
through the capability. It will create a set of secret users and
managers, walk through the setup of folders and secrets and show how end
users can access the secrets.

This section of the guide is independent of the infrastructure (server)
access use cases and only relies on the previous set up steps.

In these sections you will be swapping between users to show access
control and policy scope. It may make sense to use separate browser
profiles or incognito windows (logging out each time) to make sure you
don’t have any session state carried over from one section of the lab to
the next.
