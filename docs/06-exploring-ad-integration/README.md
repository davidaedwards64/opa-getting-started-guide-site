# Exploring AD Integration

This section provides an introduction to the Active Directory
integration feature that was introduced to Okta Privileged Access during
2025. The integration was released in two phases - the ability to
discover, manage and check-out/in AD credentials, and the ability to use
those credentials with RDP connections to domain-joined servers. The
labs in this section cover use cases from both phases.

If you have run labs from other sections of the guide, you will see a
lot of similarity within the AD integration - RDP server access is
consistent with SSH/RDP connections to local servers, and the check-out
scenario is consistent with the SaaS/Okta service accounts use cases.

The chapter provides an introduction to the integration, environment set
up steps (in addition to the common set up steps covered at the start of
this guide) and then a number of walk-through use cases exploring the
integration use cases.
