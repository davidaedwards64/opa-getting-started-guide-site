# Overview

This document is a lab guide for the Okta Privileged Access (OPA)
Generally Available (GA) release. It provides some introductory
information on the product, followed by a set of instructions on running
the various use cases to give you familiarity with the basic components
and functionality in Okta Privileged Access.

The acronym OPA will be used throughout the document to aid readability
and reduce clutter. Other acronyms will be introduced as needed.
Screenshots have been added to help understand the scenario flows. Be
aware that the product is constantly being updated, so the screen
captures in this document may not completely match what you see in your
instance.

If you have any questions relating to the content of this document
please reach out to your Okta Account Team or Okta Product Acceleration
Team contact.
