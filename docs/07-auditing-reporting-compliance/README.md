# Exploring Auditing, Reporting and Compliance Use Cases

This section provides lab instructions around some largely independent
use cases relating to auditing, reporting and compliance:

- Viewing Session Recordings

- Monitoring for Tampered Passwords

- OPA system log events and custom reporting

The first two relate to the server access use cases, so if you have not
performed all those steps there’s little value in doing them. For the
last use cases you will have events in the Okta system log from both the
Secrets and Server Access use cases and can report on them.
