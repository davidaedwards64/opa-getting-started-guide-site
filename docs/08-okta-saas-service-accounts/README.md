# Exploring Okta and SaaS Service Accounts

This section looks at the new features added (Nov 2024) for managing
Okta and SaaS application shared account passwords in OPA. The features
extend the existing OPA and Okta WIC capabilities used by OPA, such as
resources and policies, and use of the system log. You should be
familiar with the concepts covered in the previous sections (i.e. have
read through) even if you have not performed the steps covered in the
previous sections. We will not repeat the auditing and reporting steps
as they are the same as covered in the previous section.

In addition to the pre-reqs, this section covers three sets of steps:

1.  Managing Okta service accounts

2.  Managing BYO SaaS app service accounts, and

3.  Managing integrated SaaS app service accounts

Note that the screenshots used in this section are from the Early Access
version of these features and may have changed when the features become
Generally Available.
