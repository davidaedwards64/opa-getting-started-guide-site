# Introduction to Administration

In this section we will look at the initial setup of OPA from an
administrative perspective - how to configure admins in the product.
This is required no matter which use cases you choose to do later.

The section does not align with any specific section in the product
documentation. There is a section on
[<u>groups</u>](https://help.okta.com/oie/en-us/content/topics/privileged-access/pam-groups.htm)
but it is concerned with local groups. We will use Okta groups pushed to
OPA.
