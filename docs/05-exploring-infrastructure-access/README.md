# Exploring Infrastructure (Server) Access

The previous section exploited secrets management, one of the major use
cases of Okta Privileged Access. The other major use case is for
managing privileged infrastructure access, with server access being the
focus of the initial release of OPA.

This section is a series of use cases with instructions and screenshots
to help. It does not cover every feature, but covers the basics to get
you familiar with the use cases.
