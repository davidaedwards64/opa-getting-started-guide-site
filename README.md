# Okta Privileged Access Getting Started Guide (site source)

MkDocs Material source for the OPA Getting Started Guide.

```bash
uv run mkdocs serve          # preview at http://127.0.0.1:8000
uv run mkdocs build --strict # static site output in ./site
```

Content is in `docs/` (chapter folders, `media/`, `extra.css`); navigation is defined in `mkdocs.yml`.
